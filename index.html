Repair guides

Start with basic checks before attempting more invasive repairs.

Phone will not charge or power on
  1. Inspect the cable, charger and connector for visible damage.
  2. Try a known-good compatible charger and data cable.
  3. Check for overheating, moisture or battery swelling. Stop if unsafe.
  4. Follow the exact model's official troubleshooting procedure.
  5. Record symptoms before considering hardware repair.
Phone is stuck on the boot logo
  1. Record the exact model and symptoms.
  2. Try the manufacturer's recommended restart procedure.
  3. Check official recovery options for that model.
  4. Back up data if the device can still be accessed.
  5. Factory reset or firmware reinstallation may erase data. Confirm consent first.
Phone is slow or an app crashes
  1. Check available storage and restart the phone.
  2. Update apps and Android using official update channels.
  3. Review recently installed apps and permissions.
  4. Clear an app's cache through Android settings if appropriate.
  5. Back up data before any reset.
Data transfer between two phones
  1. Check both phones' battery levels and USB capabilities.
  2. Use the manufacturer's transfer tool where available.
  3. Connect with a data-capable cable and follow on-screen prompts.
  4. Approve the connection on both devices as requested.
  5. Verify copied files before erasing or resetting the old phone.

Ordinary app removal

On the customer's phone, open Settings → Apps → select the app → Uninstall, when that option is available. Some pre-installed apps can only be disabled. Do not remove system components blindly.

About UPT

Current build: mobile-first website prototype.

This version can search its sample device list, display guidance, prepare a service checklist and store basic records in browser storage.

It does not yet detect connected USB phones, flash firmware, remove system apps, execute a factory reset or unlock a device.

Those capabilities need a separately developed and tested Android application, appropriate device interfaces, permissions and supported procedures. Some operations also require the device owner's account or an authorized release.

Never enter customer PINs, passwords, recovery codes or full payment details into UPT.
